# SmartStore Demo Website

This is a static, clickable UI concept for the SmartStore file organizer project.

## Open it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Safari, or another browser.

## Included demo screens
- Overview dashboard
- Duplicate Finder (sample scan interaction)
- Organize Files
- All Files (search/filter)
- Settings

Note: The website is a visual prototype with fictional sample data. It does not access, scan, move, or delete files on your computer. The Python/Streamlit application is the separate working prototype for file operations.
